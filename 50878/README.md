Para ejecutar el programa, hay que abrir el proyecto en Visual Studio Code y luego abrir la terminal integrada con Ctrl + Ñ.

El programa utiliza el contenido del archivo:

input.txt

Por lo tanto, para probar alguno de los ejemplos incluidos fuera del proyecto, hay que copiar el contenido del input que se quiere corroborar.

Luego, en la terminal, ejecutar:

npm start

El analizador leerá automáticamente el contenido de input.txt y mostrará en consola:

tabla de lexemas/tokens
validación sintáctica
árbol sintáctico
ejecución del programa
memoria final
